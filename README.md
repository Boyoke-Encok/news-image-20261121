One image summing up the world's news of **Saturday 21 November 2026** — the
entry for the [make.fun bounty news-image-20261121](https://make.fun/bounty/news-image-20261121).

`main.ts` copies `entry.png` to `/output/entry.png` and verifies the copy
(PNG magic bytes, IHDR chunk naming 1024×1024, ≤1 MiB, IEND trailer,
identical size + SHA-256, and a re-check of the copied bytes). Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

**33 stories from 8 regions** in a 3×11 grid, each with a region tag, a
one-line headline and a two-line summary. v1 carried only 6 stories; the
leaderboard's top entries pack 30–50 stories into one image, so v2 closes
that gap while staying legible at full size and at ~300 px.
